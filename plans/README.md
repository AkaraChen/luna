  confirms untracked + gitignored. (Missing `.env.luna.example` folded into
  plan 012.)
- **`asahi.db`/`asahi-dev.db` committed** — false: `*.db` gitignored, untracked.
- **"Retry backoff is a fixed delay, README's 'exponential backoff' is wrong"**
  — false: `schedule_retry` computes `10s·2^(attempt-1)` capped at
  `retry_backoff_ms`. README claim stands.
- **Rocket 0.5 migration** — not worth doing: current version, no CVE; slow
  cadence is a watch item only (revisit if >12mo without a release).
- **minijinja SSTI via issue data** — cleared: issue fields render as template
  *values*, not template source. (LLM-level prompt injection remains a real
  surface — framed in plan 002's maintenance notes.)
- **Dashboard XSS sinks** — cleared: all routed through `sanitizeRichText`'s
  tight DOMPurify allowlist (which is why the dompurify version bump in 006
  matters).
- **`AgentSessionFactory` premature abstraction** — rejected: it's a
  legitimate test seam (`FakeSessionFactory`).
- **Full `orchestrator::run()` integration test** — not worth the harness
  cost now; helper-level coverage is strong (29 tests / 215 asserts).
- **Asahi API layering violations** — none found: `api → service → entity`
  is clean; the debt is file size, not layering.
